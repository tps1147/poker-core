# Academy lesson plan format (draft 0, from the accepted M1 v1 direction)

Every lesson is one node of `src/learn/v1/academyTree.mjs`. A plan fills these fields before any media is made. Plans are reviewed before a batch is produced.

## Fields

| Field | What goes in it |
|---|---|
| Node and track | Tree id, track, prerequisites (from the tree, not restated by hand) |
| One idea | The single sentence a learner should be able to say afterwards |
| Belief it fixes | The misconception, in the learner's words |
| Hook | One question on screen in the first 4 s, answerable by the end |
| Predict | What the learner commits to before the explanation (tap in the app) |
| Build | The diagram or table moment that carries the idea, and the colour meaning used |
| Prove | How the claim is shown over many repetitions, not one lucky result |
| Transfer | A changed spot where the learner works first (faded worked example) |
| Rule | The recap card: one formula or one sentence |
| Checks | Guided → practice → fresh decisions (server-graded); a delayed check scheduled by policy |
| Formats | From the tree: film, table, toy, worked, contrast, decision, drill, match |
| Characters | Coach or rival only where they add something (a thinking moment, a rival's all-in) |
| Truth sheet | Every number and card on screen, computed by a script, plus sources for history facts |
| Sound | Silent-complete captions first; narration added later and timed to captions |

## House style (from M1 v1)

- One focus per beat. The table leaves when the math starts; it returns for the next hand.
- Colour carries one meaning everywhere: green = your chance, blue = your call or price, coral = their bet, gold = the final pot, white = chips already in.
- Labels sit on the thing they name and appear with it.
- Game feel is spent where the answer lands: slams, count-ups, count × value tallies, stamps. Never on decoration.
- Results never grade a decision. Show the many-repetitions view instead.
- Captions: one idea, 3–6 s on screen, at least 54 px at 1080 wide. Minimum type 36 px.
- BitBlur near-black ground with glass panels for diagram beats; the real Flop52 table and cards for table beats.
